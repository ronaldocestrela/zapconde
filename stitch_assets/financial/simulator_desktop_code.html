O sistema aplica as regras padrão condominiais conforme o Código Civil Brasileiro (Art. 1336):

  • Juros Pro-rata: Juros moratórios de 1% ao mês, calculados proporcionalmente por dia de atraso (0,0333% ao dia).
  • Perda de Desconto: Descontos de pontualidade são automaticamente invalidados após a data original de vencimento.
